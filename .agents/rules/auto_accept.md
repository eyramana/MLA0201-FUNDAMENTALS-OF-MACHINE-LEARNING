# Auto-Accept Development Rule

- **Automatic Execution**: The agent should automatically accept and execute routine file edits, code refactoring, test suites, and terminal commands within the workspace scope.
- **Streamlined Workflow**: Do not halt for redundant confirmation prompts during multi-step coding or testing tasks.
- **Security Scope**: Restrict automatic action to the `CropGuard_AI` workspace. Require explicit confirmation only for irreversible or high-risk actions.
